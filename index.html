Olist Delivery Time Estimation

Built an end-to-end machine learning project using the Brazilian Olist e-commerce dataset to estimate delivery time in days. Compared regression models and deployed a Stacking ensemble combining HistGradientBoosting, Random Forest and Extra Trees, with Ridge regression learning how to combine their predictions. The selected model achieved a test MAE of 4.39 days on unseen orders.
